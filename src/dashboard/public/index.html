      Set up Hujan in Discord

      Step 1 of 7

      Before you start

      This guide shows exactly where to click in Discord. You will create an application, invite its bot to your server, and copy three IDs into Hujan.

      • A Discord account.
      • A server where you have Manage Server (usually your own server).
      • About five minutes.

      The guide only fills in the Settings form. Nothing is saved until you choose Save changes, and your bot token stays on this device.

      The illustrations below are simplified mock-ups, not live Discord windows. Button names match the real pages.

      Create the application

      1. In the Developer Portal, choose New Application.
      2. Name it (for example Hujan) and choose Create.
      3. On General Information, copy the Application ID and paste it below.

      Create the bot and copy its token

      1. Open the Bot page and choose Add Bot if asked.
      2. Choose Reset Token, then Copy, and paste the token below.
      3. Further down the same page, under Privileged Gateway Intents, turn on Message Content Intent and choose Save Changes.

      The token is a password. It is shown only once; never share it or post it in Discord. If it leaks, use Reset Token again and paste the new one here.

      Invite the bot to your server

      Open this invite link, choose your server, and choose Authorize. The server appears only if you have Manage Server there.

      Permissions requested: View Channel, Send Messages, Read Message History, Attach Files, Embed Links, Connect, Speak, Manage Nicknames. Hujan needs these for chat, ambience and the nickname command.

      Turn on Developer Mode

      Developer Mode adds the Copy ID entries you need in the next step.

      • Discord on desktop: User Settings (the cog beside your name) → Advanced → turn on Developer Mode.
      • Discord on mobile: your avatar → Advanced → turn on Developer Mode. Long-press instead of right-click later.

      Copy your server ID and owner ID

      1. Server ID: right-click your server icon (or its name) → Copy Server ID. Paste it below.
      2. Owner ID: right-click your own avatar or profile → Copy User ID. Paste it below. This is the account allowed to control Hujan.

      Review and finish

      Check the values below. Fill in settings copies them into the Discord section; then choose Save changes, run Test saved connection, and start the bot.

        Slash commands are registered by the separate existing action after the connection works. If the test says the bot cannot access the server, repeat the invite step with this application's invite link.
